项目简介

车队每天要处理几十张磅单：装车一张、卸货一张，车牌号、两个时间点、毛重皮重、司机信息都是人工抄进 Excel， 抄错一个数字，月底对账就差出一吨货。这个课程设计要解决的就是这一步——把磅单截图交给程序识别，人只负责核对。

程序用 PySide6 编写桌面界面，RapidOCR 做本地文字识别，数据以 CSV 存放在程序目录下， 不依赖数据库、不联网，整个软件拷到任何一台 Windows 电脑上都能直接运行。

四个核心功能

覆盖从录单到出报表的完整流程。

磅单截图识别

支持装车磅单和卸货计量单两种版式，自动提取车牌号、时间、净重、司机姓名、身份证号和收货单位。识别结果先弹窗核对，确认后才写入表格。

当日信息表

11 个字段，可直接在表格里修改。同一辆车的装车与卸货自动合并成一行，状态自动更新为「准备 / 装车 / 卸货 / 完成」，切换日期时自动保存。

查询与导出

查询框支持任意关键词：车牌、省份简称、司机姓名、电话、身份证号、日期都能命中。当天的表格可一键导出为 Excel。

运输统计

选择时间段，列出全部明细并按车牌统计运输次数，跨天的同一趟自动去重。明细和汇总都能导出 CSV，直接交给财务。

技术实现

课程设计涉及的技术点，方便答辩时展开说明。

界面：PySide6 / Qt 6

主窗口 + 页签布局，表格用 QTableWidget 自定义委托实现下拉选择；OCR 放在独立线程里执行，识别过程中界面不会卡住。

识别：RapidOCR + PP-OCRv3

基于 ONNX Runtime 的本地推理，先把文字框按行归并成表格结构，再用关键词定位字段；不需要联网，也不需要 GPU。

数据：CSV + openpyxl

每天一个 CSV 文件，字段固定 11 列，Excel 可直接打开；导出功能用 openpyxl 生成 xlsx，统计表按车牌合并计次并去重。

打包：PyInstaller onedir

连同 Python 解释器、Qt 运行库和 OCR 模型一起打包，目标机器无需安装 Python，双击即可运行；源码约 1650 行。

数据存在哪里？

程序目录下的 数据 文件夹：每天一个 CSV（按日期命名），司机登记表一个 CSV，备份在 数据\备份 里。程序每 60 秒自动保存，写盘前先备份。

换电脑怎么迁移？

整个文件夹拷过去即可；如果只想搬数据，拷 数据 文件夹到新电脑同样的位置。

支持哪些磅单？

内置装车磅单和卸货计量单两种版式。其他版式能识别的字段会填上，缺的在核对弹窗里手动补——每个字段都可以改。

# 车辆管理系统

装卸货登记与运输统计的 Windows 桌面程序（课程设计作品）。

把微信里的磅单截图拖进窗口，程序自动识别车牌号、时间、净重和司机信息；每天的记录保存在本地 CSV 里，月底可以按车牌统计运输次数并导出报表。

> 本仓库同时托管该项目的介绍网页：`index.html`（主页面）和 `guide.html`（操作演示）。

---

## 功能

- **磅单识别录入**：支持装车磅单、卸货计量单两种版式，识别结果先弹窗核对，确认后入库
- **当日信息表**：11 个字段，装车与卸货自动合并成一行，状态自动更新（准备 / 装车 / 卸货 / 完成）
- **任意关键词查询**：车牌、省份简称、司机姓名、电话、身份证号、日期都能直接搜
- **运输统计**：按时间段汇总明细，按车牌统计运输次数，跨天同一趟自动去重
- **司机身份登记**：身份证号为主键，可从历史记录一键导入
- **导出**：当日表导出 xlsx，统计表导出明细 / 汇总 CSV
- **自动保存**：每 60 秒自动保存，写盘前备份，保留最近 20 份

## 技术栈

| 层 | 选型 |
|---|---|
| 界面 | PySide6（Qt 6），QTableWidget + 自定义委托 |
| 文字识别 | RapidOCR 1.2 + PP-OCRv3 模型（ONNX Runtime，本地推理） |
| 数据存储 | CSV（每天一个文件，UTF-8 BOM，Excel 可直接打开） |
| 导出 | openpyxl |
| 打包 | PyInstaller（onedir），免安装 |

代码规模：主程序约 1280 行，统计程序约 370 行。

## 运行

**直接使用**：解压发布包，双击 `车辆管理系统.exe`。

**从源码运行**：

```bash
pip install -r requirements.txt
python 车辆管理系统.py
```

**打包**：双击 `打包.bat`，产物在 `dist/` 下。

## 关于本仓库里的网页

`index.html` 与 `guide.html` 是纯静态页面，不依赖任何外部资源，直接用浏览器打开即可：

- `index.html` — 项目介绍、功能、技术实现
- `guide.html` — 六步界面走查（演示用，支持键盘 ← → 切换）

## 说明

- 程序不含任何联网行为，磅单图片与登记数据不会离开本机。
- 识别基于固定版式的磅单截图，遇到其他版式时可在核对窗口手动修正。
- 逐日数据以 CSV 明文保存，方便随时用 Excel 检查或备份。
